# ROHAND ROH-AP001 MUJOCO 包

rohand mujoco 包

## 1.准备

```BASH
pip install mujoco
```

## 2.话题

| 名字            | 描述                                                    |
| --------------- | ------------------------------------------------------- |
| "index_finger"  |               通过改变食指的位置来控制其弯曲             |
| "middle_finger" |               通过改变中指的位置来控制其弯曲             |
| "ring_finger"   |              通过改变无名指的位置来控制其弯曲            |
| "little_finger" |              通过改变小拇指的位置来控制其弯曲            |
| "thumb_root"    |            通过改变大拇指旋转的位置来控制其弯曲          |
| "thumb"         |              通过改变大拇指的位置来控制其弯曲            |

## 3.运行

运行 'main.py' 文件并且根据提示选择类型.

```BASH
python main.py
```
